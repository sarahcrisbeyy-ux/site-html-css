**Projeto HTML e CSS**


Este é um projeto simples de uma página web construída utilizando apenas HTML e CSS. O objetivo é demonstrar a criação de uma estrutura básica de site com um design responsivo e estilizado.



**Funcionalidades:**

**Layout limpo e organizado**

**Uso de semântica HTML adequada**

**Estilos CSS aplicados para cores, tipografia e espaçamento**

**Responsividade para diferentes tamanhos de tela (desktop, tablet e mobile)**

**Componentes básicos como cabeçalho, navegação, seção principal, e rodapé**


**Ferramentas usadas:**

HTML5

CSS3
